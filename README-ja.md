# Word Wolf

Google スプレッドシート + GAS のワードウルフサンプル

## 事前準備

スプレッドシートで、下記シートを用意します

### Config

| Status | StartTime| Limit| Title | WoflName | CitizenName |
| ------ | -------- | ---- | ----- | -------- | ----------- |
|      |      | 300 |ワードウルフ オンライン|人狼|村人|

- Status, StartTime … システムが利用
- 話し合い時間。指定しないと 300秒
- Title, WorlName, CitizenName … 入力した文字がゲーム中で使われます

### Words

1行で1つのお題。どの行が出題されるか、左右どちらが狼かはランダム

| ワード1 | ワード2 |
| ------- | ------- |
|         |         |

### Players

登録済みユーザーのみ参加可能

- UserEmail … 必須。ログインする Google アカウント
- Nickname … 必須。ゲーム中の表示名
- Facilitator … true or false。true だと進行役になって、画面構成が変わります。チェックボックスにするといいかも
- 他の列はシステムが利用

| UserEmail | Nickname | Role | Word | Checked | Vote | Facilitator |
| --------- | -------- | ---- | ---- | ------- | ---- | ----------- |
|           |          |      |      |         |      |             |

## 進行役ガイド

進行役もゲームに参加するので、事前の種明かしなしです。Players シートで G 列にチェックを入れた人は、各画面に管理用ボタンが表示されます。

|      | プレイヤー                 | ファシリテーター             |
| ---- | -------------------------- | ---------------------------- |
| 1    | 「進行役が準備しています」 | 狼の人数を決めて、お題を配布 |
| 2    | ワードを確認する           | ＋ゲーム開始                 |
| 3    | カウントダウン             | ＋投票を開始する             |
| 4    | 投票                       | ＋正解を表示する             |
| 5    | 結果発表                   | ＋次のゲームへ               |

## その他

- ポーリングして画面を書き換えてるので、各プレイヤーの画面は数秒ずれます。
- ポーリング間隔は 3 秒。変更したい時は index.html の最下方「3000」を変更する
